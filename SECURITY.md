# Security Policy

## Supported Versions

AeroCore is currently maintained as a single active development line. Security
fixes are applied to the latest state of the project.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older snapshots | No |

## Reporting a Vulnerability

If you believe you have found a security issue, please do not open a public
issue with exploit details.

Instead, report it privately with:

- a clear description of the issue,
- affected files or components,
- reproduction steps or proof of concept,
- impact assessment if known.

If a private reporting channel is added later, update this file with that
contact path. Until then, repository maintainers should handle reports through
private GitHub security reporting when enabled.

## Scope

Security-sensitive areas may include:

- configuration parsing,
- logging and file handling,
- command-line argument handling,
- future networked telemetry or remote-control integrations.

## Disclosure Process

Maintainers should aim to:

1. acknowledge receipt promptly,
2. validate and triage the report,
3. prepare and test a fix,
4. publish the fix and coordinated disclosure notes when appropriate.
